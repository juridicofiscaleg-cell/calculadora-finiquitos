# Calculadora de Finiquitos — EG Empresarial

Aplicación web para estimar finiquitos y liquidaciones laborales conforme a la Ley Federal del Trabajo, con descarga de PDF profesional.

## Escenarios

- Renuncia voluntaria
- Despido injustificado (liquidación)
- Despido justificado
- Término de contrato / obra

## Conceptos

Salarios pendientes, aguinaldo proporcional, vacaciones (tabla Art. 76), prima vacacional 25%, prima de antigüedad, indemnización de 3 meses y 20 días por año (según el caso), más conceptos y descuentos libres.
